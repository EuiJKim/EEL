# EEL 홈 — Editorial Spreads 디자인 스펙

**날짜:** 2026-06-24
**상태:** APPROVED (디자인 합의 완료, 구현 계획 대기)
**범위:** 홈(`/`) + 카테고리 필터(`/?category=`) + Available(`/available`)의 작품 영역(GridLayout) 재구성. 사이드바·헤더·Projects는 건드리지 않음.

---

## 1. 목표 (왜 바꾸나)

홈페이지의 #1 임무 = **작품 쇼케이스 / 인지도**. 판단 기준은 단 하나 — "작품이 주인공인가?"

현재 진단에서 나온 고칠 점:
- **B. 작품이 작고 균일하다** — 데스크탑 4열 / 모바일 2열, 전부 같은 크기라 강약·리듬이 없음.
- **C. 첫인상 '한 방'이 없다** — 들어오자마자 바로 격자. 시선을 잡는 대표작이 없음.
- **D. 분위기가 약하다** — 작품 사진이 브랜드인데 "갤러리" 느낌까진 안 감.

유지(안 건드림): **A. 사이드바 껍데기** — 로고·시계·인덱스 등은 그대로.

선택한 방향: **Editorial Spreads** — 잡지 펼침면처럼 줄마다 구성이 다른 레이아웃. "쇼케이스(많이 보여주기) + 리듬 + 히어로"를 가장 균형 있게 잡음.

---

## 2. 레이아웃 구조

### 2.1 히어로 (C)
- 작품 영역 맨 위에 **대표작 1점**을 크게.
- 선정 방식: 데이터에 `featured` 플래그. **전체 보기(`category=all`)** 에선 `featured: true`인 첫 작품이 히어로.
- **카테고리 필터 시**: 그 카테고리의 첫 번째 작품이 히어로 (해당 카테고리에 featured가 없을 수 있으므로).
- 히어로는 다른 타일보다 크게(데스크탑 풀폭에 가깝게, 모바일 풀폭), 제목은 디스플레이 폰트(Gravitas One).
- 히어로도 클릭하면 `/works/[id]`로 이동 (일반 카드와 동일).

### 2.2 리듬 (B)
히어로 아래로 **반복되는 스프레드 패턴**으로 나머지 작품을 배치. 데이터 개수와 무관하게 동작(순서대로 채움).

**데스크탑 반복 단위 (작품 8점 주기):**
1. `large + 2 small` — 큰 1점(2칸 너비) + 작은 2점(1칸 너비, 세로 스택) = 3점
2. `3 equal` — 동일 크기 3점 = 3점
3. `2 equal` — 동일 크기 큰 2점 = 2점
→ 이후 1번부터 반복.

**모바일 반복 단위:**
- 풀폭 큰 작품 ↔ 2열 작은 작품 쌍을 번갈아. (예: 풀폭 1 → 2열 2 → 풀폭 1 → …)

> 구현 노트: 인덱스 기반 패턴(`index % cycleLength`)으로 각 작품에 타일 크기(span)를 부여. 별도 레이아웃 엔진 없이 CSS Grid의 `col-span`/`row-span` 또는 flex 행 구성으로. 과설계 금지 — 하드코딩된 패턴 배열로 충분.

### 2.3 분위기 (D)
- **여백 확대** — 스프레드 사이 간격을 현재보다 넉넉히. 갤러리 벽처럼.
- **캡션 정제** — 히어로 제목 = Gravitas One. 일반 작품명 = Inter. 카테고리·연도 = 작게(Staatliches 라벨 톤).
- **호버** — 살짝 확대(scale ~1.03) + 어두운 베일 정도. **글로우·레인보우·blur 금지**(EEL 가드레일 준수).
- **톤 유지** — 보라 배경(`#110D1C`) 그대로. 색은 작품 사진이 담당.

### 2.4 이미지 비율
- `public/products/*` 원본은 전부 세로(~2666×3333). object-cover로 가로 강제 시 잘림 주의(CLAUDE.md 함정).
- 히어로·풀폭 타일은 세로비를 살리거나 완만한 비율(예: 4:5, 3:4)로. 작은 타일은 정사각 또는 4:5. 잘림 최소화.

## 4. 반응형

- **데스크탑(md+):** 사이드바 + 작품 영역. 작품 영역에 히어로 + 데스크탑 스프레드 패턴.
- **모바일(<md):** MobileHeader + 작품 영역(히어로 풀폭 + 모바일 번갈이 패턴) + MobileFooter + 스티키 CTA.
- 터치 타깃·스크롤 동작 등 기존 모바일 규칙 유지.

---

## 5. 엣지 케이스

- **작품 0개(필터 결과 없음)** — 기존 빈 상태 메시지 유지("현재 구매 가능한 작품이 없습니다…").
- **작품 1~2개(카테고리 필터)** — 히어로만, 또는 히어로 + 짧은 행. 패턴이 깨지지 않게 개수 적을 때 graceful 처리.
- **featured 미지정** — 전체 보기에서 featured가 하나도 없으면 첫 작품을 히어로로 폴백.
- **Available(2점뿐)** — 히어로 + 1점. 휑하지 않게 히어로 비중 조절.

## 7. 성공 기준

- 홈 진입 시 **대표작이 가장 먼저·크게** 보인다.
- 스크롤하면 **작품 크기가 줄마다 달라져** 리듬이 느껴진다.
- 데스크탑/모바일 모두 **작품이 현재보다 크고**, 사이 여백이 넉넉하다.
- 기존 동작(카테고리 필터, 작품 클릭→상세, 빈 상태) 깨지지 않는다.
- 빌드·타입체크 통과, EEL 디자인 가드레일(글로우/레인보우/blur 금지) 준수.
