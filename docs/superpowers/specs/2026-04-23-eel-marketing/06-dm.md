# 06. DM Funnel

## Why DM Matters
광고·포스팅의 목적은 전부 **"DM까지 오게 만드는 것"**. 일단 DM 오면 50%가 여기서 결정됨.

## 유입 경로 3가지
- 경로 A: IG 포스트 → DM
- 경로 B: 웹사이트 → `/order` 폼 제출 → 이메일
- 경로 C: 광고 → IG 프로필 → 하이라이트 → DM

## Response Speed Rules
- Phase 2 (Week 3-6): **24시간 이내**
- Phase 3 (Week 7-12): **12시간 이내** ← 전환율 2배 차이

## Funnel Stages (전환율 추적)

| Stage | 정의 | Healthy Conv Rate |
|---|---|---|
| 1 | DM 접수 | — |
| 2 | 대화 이어짐 | 60~80% |
| 3 | 견적 제시 | 30~50% |
| 4 | **계약금 입금** 🎯 | 20~40% |
| 5 | 작품 완성·배송 (포트폴리오화) | — |

**종합 Conv Rate: 5~15%**

**역산:** 계약 1건 = DM 10~20건 필요. Phase 2-3 합쳐 90일 목표.

## Tools
- IG 기본 DM 인박스 충분
- Meta Business Suite 앱 (모바일 통합 관리)
- Auto-reply 설정 (Settings → Professional → Automated responses)
