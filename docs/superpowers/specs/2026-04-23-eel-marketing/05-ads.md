```
Campaign: Traffic → Profile Visit
├── Ad Set A: Lookalike 1% (from 1,335 팔로워) — 일 ₩10,000
├── Ad Set B: Broad Interest — 일 ₩10,000
│   (서울·경기 28-48, Interior/Dezeen/Monocle/Handmade/Mid-century modern)

    (eel-studio.me 방문자 + IG engager)
```

**KPI (Phase 2):**
- CTR ≥ 1.5%
- CPC ≤ ₩1,000
- Profile visit / ₩1,000 spend ≥ 0.8
- DM 유입 월 3~5건
