# 09. Open Questions (User Prerequisites)

**Phase 1 실행 블로커.** 사용자가 준비해야 하는 것들.

## P1. Meta Pixel ID
- **어디서:** business.facebook.com → Events Manager → Connect Data Sources → Web
- **이름:** "EEL Pixel"
- **결과:** 15~16자리 ID → `.env.local`에 `NEXT_PUBLIC_META_PIXEL_ID=...`

## P2. OG Image
- **크기:** 1200×630 (JPG 또는 PNG)
- **콘셉트:** 완성 작품 1점 Hero Shot (어두운 배경, 중앙 배치) 또는 작업실 분위기
- **용도:** DM·카톡·Dezeen 피치에 링크 공유 시 썸네일

## P3. About 페이지 자료

### 사진 1장
- 작가 또는 작업실 분위기
- 세로 4:5 비율 권장, 1200px+

### 1인칭 글 300~500자 (한국어)
- 왜 레진 작업을 시작했는지 (시작 이야기)
- 왜 한 작품에 3주가 걸리는지 (작업 철학)
- 재료 선택 기준 (오크·레진·안료)

## 부가 결정 사항
- 지금 시작할 작품 있는지 (Process 시리즈 W1 게시용)
- OG image로 쓸 대표 작품 선정
- 일 광고비 ₩30,000 고정 vs 상황 따라 ±20% 허용
