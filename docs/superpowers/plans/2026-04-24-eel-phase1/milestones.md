## Phase 2: Launch (Week 3-6)

### M1: Meta Business Manager + IG 연결 (Week 3 Day 1, 45분)
- business.facebook.com → Create Business → @eel.eel.eel.eel 연결
- 본인 명의 결제 카드 등록
- Ad Account "EEL Ads" 생성 (KRW, Asia/Seoul)

### M2: Phase 2 콘텐츠 백로그 구축 (Week 3 Day 2-3)
- 4주치 포스트 초안 (Process / Hero / Detail / Voice)
- Claude가 캡션 + 아카이브 작품 선정 도움

### M3: IG 바이오 + DM 템플릿 업데이트 (Week 3 Day 4)
- 바이오 3줄 재작성 (spec 참조)
- DM 템플릿 3종을 IG Saved Replies에 저장

### M4: Phase 2 광고 런칭 (Week 3 Day 5)
- Campaign: Traffic → Profile Visit
- 3 Ad Sets: Lookalike 1% + Interest + Retargeting
- 일 ₩30,000 × 28일
- Creative: Use existing post

### M5: 주간 리뷰 리추얼 (Week 3-6 매주 월)
- Ads Manager 30분 + IG Insights 15분
- DM 응대 + 퍼널 기록
- `.gstack/marketing/week-N.md` 작성

### M6: Day 30 체크포인트 (Week 6 끝)
- 합격 기준 체크 (팔로워 +100~200, DM 3~5건, CTR ≥1.5%)
- Phase 3 조정 사항 정리

## Phase 3: Convert (Week 7-12)

### M7: Campaign을 Conversions → Lead로 전환 (Week 7 Day 1)
- Pixel 데이터 충분 누적 확인
- 승자 Ad Set만 유지, Conversions Objective로 전환

### M8: Lookalike 1% → 3% 확장 (Week 7 Day 2)
- 기존 Lookalike 복제 → 3% 버전

- 크리에이티브: 승자 포스트 + 변형 2개

- 견적 → 계약 전환 집중
