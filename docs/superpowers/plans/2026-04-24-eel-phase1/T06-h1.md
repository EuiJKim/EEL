# T06. Home page h1 tag

**Status:** ✅ DONE — commit `9236036`

## 목적
SEO 기본. 홈에 h1 태그 0개 → Google이 페이지 주제를 인식하기 어려움.

## 파일
- Modify: `app/page.tsx`

## 변경
히어로 섹션의 "EEL" 브랜드 마크를 `<p>` → `<h1>` 로 교체. 모든 className·style·텍스트 그대로 유지 → 시각 변화 0.

```tsx
// Before
<p className="hero-logo ...">EEL</p>

// After
<h1 className="hero-logo ...">EEL</h1>
```

## 규칙
- 페이지 전체에 정확히 h1 1개
- Footer의 "EEL Copyright" 텍스트는 `<p>` 유지 (브랜드 마크만 h1)

## 검증
브라우저 콘솔:
```javascript
document.querySelectorAll('h1').length  // → 1
```

git add app/page.tsx
